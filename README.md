# Nightwatch — citizen skywatch gear site (skeleton)

Affiliate gear site for night-sky observation equipment: telescopes, binoculars,
star trackers, accessories. Angle: **citizen skywatch** — gear for people who
want to look at the night sky themselves and capture what they see
(「自己睇返轉頭」), funneled from realufo.org's audience.

**Status: skeleton, NOT published.** Per PUBLISH RULE, nothing goes live
(site, social, anywhere) without Hector's explicit OK.

## Quickstart

```bash
cd ~/workspace/sites/skygear
python3 build.py                    # builds dist/
AMAZON_TAG=yourtag-20 python3 build.py
python3 build.py --dump-sql         # INSERTs for the D1 gear_picks table
```

`dist/` is the deployable output (commit it to the repo — Cloudflare Pages
with no build command, same as the globalnewsshorts pattern).

## Layout

- `src/site.json` — brand, tagline, categories, domain (**placeholders — rename before launch**)
- `src/products.json` — product manifest: the build-time source of truth
- `src/style.css` — dark night-sky theme, mobile-first
- `src/indexnow.key` — generated on first build (per-host key)
- `build.py` — static generator
- `dist/` — generated: index, about, 4 category pages, 6 product pages,
  `sitemap.xml`, `robots.txt`, `llms.txt`, `feed.xml`, `<key>.txt`
- `db/migrations/0001_gear_picks.sql` — D1 affiliate table (realufo `0040_affiliate.sql` pattern)

## Adding a product

Add an entry to `src/products.json`:

```json
{
  "slug": "brand-model",
  "name": "Brand Model",
  "category": "telescopes",
  "tagline": "One-line hook.",
  "blurb": "2–3 sentences, citizen-skywatch angle.",
  "price_usd": 500,
  "pros": ["..."], "cons": ["..."],
  "specs": {"Aperture": "130 mm"},
  "amazon_query": "Brand Model telescope",
  "retailers": [
    {"name": "High Point Scientific", "url": "TODO: affiliate deep link", "note": "..."},
    {"name": "Amazon", "url": "AMAZON", "note": "..."}
  ]
}
```

- `"url": "AMAZON"` → Amazon search URL with `AMAZON_TAG` (realufo pattern).
- `"url": "TODO: ..."` → renders a "Link coming soon" placeholder button.
- Prices render as "around $X" — approximate street prices, never live quotes.

## Affiliate program checklist (do before launch)

1. **Amazon Associates** — set `AMAZON_TAG` (currently `yourtag-20` placeholder).
   Note: electronics/cameras pay ~2–3% with a 24h cookie — use as fallback, not the lead.
2. **High Point Scientific** — apply for their affiliate program; replace the
   `TODO:` URLs with deep links (higher commission than Amazon).
3. **Orion Telescopes** (via CJ/Pepperjam/AvantLink, 1–8%, 90-day cookie).
4. **Levenhuk** (20%, 90-day cookie) / **Adorama** / **B&H** as applicable.
5. Re-run `build.py --dump-sql`, apply `0001_gear_picks.sql` + seed INSERTs to
   D1 via the Cloudflare dashboard (dashboard paste pattern — API is broken from this VM).
