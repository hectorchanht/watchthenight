# Watch the Night — Newsletter Plan

## Status

The site already renders newsletter UI (homepage section + footer form) generated by `build.py`.
It posts to `newsletter_endpoint` in `src/site.json`. The endpoint is currently **empty**,
so both placements render a "coming soon" state — never a dead form.

## How to wire it (at deploy time)

Follow the RealUFO email pattern (D1 + Resend, double opt-in):

1. **Worker route** `POST /api/subscribe` on the watchthenight.com Worker/Pages project:
   - Accept `email` (form-encoded or JSON). Validate format, rate-limit by IP.
   - Insert into D1 table `email_subscribers` (same schema as RealUFO: email, token, confirmed, created_at).
     If the email already exists and is confirmed, return 200 silently (no error leak).
   - Send a confirmation email via Resend (from `Watch the Night <hello@watchthenight.com>`)
     containing a `GET /api/confirm?token=<token>` link.
   - `GET /api/confirm` flips `confirmed=1` and shows a plain "You're in" page.
2. **Set the endpoint**: put the full URL (e.g. `https://watchthenight.com/api/subscribe`)
   into `newsletter_endpoint` in `src/site.json`, rebuild, and push.
3. The form is a plain HTML POST — no JavaScript needed, works cross-origin.

## Sending cadence (suggested)

- Meteor-shower reminders (Orionids, Leonids, Geminids + the big 2027 showers).
- New gear pick / roundup announcements.
- No weekly noise — only when it's worth looking up. Matches the on-site copy.
